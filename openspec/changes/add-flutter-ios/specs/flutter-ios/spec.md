# flutter-ios 模块规格说明

- 版本：202611010002
- 最后更新：2026-11-01
- 模块名称：flutter-ios（Flutter iOS 客户端）

## 业务概述

flutter-ios 为现有 Flutter 收藏应用提供 iPhone/iPad 运行目标。iOS 端与 Android 端复用同一套 Dart 页面、认证、收藏空间和数据接口，并保留 kitchen 与 star 两种构建模式。

## 核心业务流程

- 构建时通过 `APP_TYPE=kitchen` 或 `APP_TYPE=star` 选择应用模式。
- iOS 用户使用现有账号登录，令牌继续存储在 iOS Keychain 中。
- 用户可以浏览、搜索、创建、编辑、移动和删除收藏，并可修改密码。
- 收藏链接使用 iOS 系统或已安装应用打开；无法打开时向用户提示失败。
- iOS 原生分享扩展未配置时，应用仍可正常启动和使用，分享入口不应导致崩溃。

## 页面布局约束

- iPhone 使用现有窄屏抽屉导航，iPad 使用现有宽屏左侧导航。
- 密码和令牌不得显示在日志、页面明文或 URL 中。
- iOS 状态栏、键盘和安全区域不得遮挡主要输入框及操作按钮。

## 接口说明

本模块不新增业务接口，继续使用现有 `/api/auth` 和 `/api/bookmarks` 接口。
