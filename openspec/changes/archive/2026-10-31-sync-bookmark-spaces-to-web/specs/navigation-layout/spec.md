# Spec Delta

## MODIFIED Requirements

### Requirement: 工具作为左侧导航菜单组

系统 SHALL 将工具呈现为左侧导航中的文件夹式菜单组，工具组本身不得作为没有层级的单一顶层页面入口；现有工具功能 SHALL 作为其子菜单项展示。收藏夹在工具菜单下 SHALL 作为二级目录组呈现，其下包含“疯狂的厨房”和“鲸界”两个独立入口。

#### Scenario: 工具组展开

- **WHEN** 用户点击工具菜单组
- **THEN** 系统展开工具子菜单并显示现有工具入口，用户可以继续选择具体工具页面

#### Scenario: 工具组收起

- **WHEN** 用户再次点击已展开的工具菜单组
- **THEN** 系统收起工具子菜单，且不改变当前已加载页面的业务内容

#### Scenario: 从工具子菜单进入数据传输

- **WHEN** 用户点击工具组中的数据传输入口
- **THEN** 系统进入现有数据传输页面，使用原有路由、认证要求和业务功能

#### Scenario: 收藏夹二级目录展开与选择

- **WHEN** 用户在工具菜单中点击“收藏夹”目录
- **THEN** 收藏夹展开并展示“疯狂的厨房”与“鲸界”入口，点击任一入口进入对应模式的收藏管理页面

## ADDED Requirements

### Requirement: 页面最外部高度限制与禁止外部滚动条

系统 SHALL 将 Web 端最外层容器高度限制为 95vh，且页面整体最外层（包含 html、body 及最外层应用外壳）MUST 禁止出现外部滚动条（即禁止产生整页级垂直或水平滚动条），内容超出时由内部主工作区或侧边菜单内部自适应滚动。

#### Scenario: 页面视口高度限制

- **WHEN** 用户在任意桌面或 Pad 浏览器中加载 Web 客户端
- **THEN** 最外层应用容器高度为 95vh，页面视口整体不产生外部滚动条

#### Scenario: 内容超出视口高度

- **WHEN** 当前页面内容或目录树高度超出 95vh 可视区域
- **THEN** 溢出内容在各局部容器内部滚动，外层页面位置和导航结构保持稳定不被滚动挤出视口
