# Proposal

## Why

当前首页导航的交互表达和视觉层级不够清晰：展开/收起菜单使用文字且位置不符合鲸境品牌布局，左侧导航选中态又使用蓝色，与顶部墨绿色视觉不一致。同时“工具”作为顶层单项，无法表达其下属功能的菜单分组关系。此次调整将统一导航的交互位置、颜色和层级，降低用户理解成本。

## What Changes

- 将展开/收起左侧菜单改为鲸境标识左侧的小图标按钮，不再使用文字作为主要控制入口。
- 保留菜单展开和收起能力，并为图标按钮提供可识别的悬停、聚焦和无障碍标签状态。
- 将左侧导航当前选中态的文字、图标和强调色统一为顶部导航使用的墨绿色，不再使用默认蓝色。
- 将“工具”调整为左侧导航中的可展开菜单组/文件夹入口，其下承载现有工具相关页面，例如数据传输。
- 保持现有路由地址、认证要求和工具页面业务功能不变，仅调整导航呈现与交互组织。

## Capabilities

### New Capabilities

- `navigation-layout`: 定义鲸境应用首页的左侧导航折叠控制、统一选中态视觉和工具菜单分组行为。

### Modified Capabilities

- 无。当前项目的既有 `specs/` 目录未包含首页导航能力规格，因此以独立能力规格建立该行为契约。

## Impact

- 影响 `source/web/src/layouts/AppLayout.vue` 及其关联样式、菜单组件或图标引用。
- 可能影响 `source/web/src/App.vue` 的布局组合，以及现有首页、工具页和数据传输页的导航配置。
- 不新增或修改后端 API、认证流程、路由路径和业务数据模型。
- 需要在桌面和 Pad 浏览器尺寸下验证菜单展开/收起、选中态和工具分组的可用性。
