# Spec Delta

## ADDED Requirements

### Requirement: 主页目录递归内容展示

Flutter 主页 SHALL 只显示收藏视频卡片；目录切换由左侧目录导航完成，当前目录视图包含该目录及其后代目录的视频。

#### Scenario: 主页浏览目录

- **WHEN** 用户从左侧目录树选择目录
- **THEN** 主页隐藏子目录卡片并展示该目录及后代目录的收藏视频

### Requirement: 目录树与选择器折叠

左侧目录树和新增页面目录选择器 SHALL 支持父目录折叠/展开；折叠按钮位于目录项右侧，不遮挡目录名称。

#### Scenario: 折叠父目录

- **WHEN** 用户点击父目录右侧折叠按钮
- **THEN** 所有子目录从当前树视图隐藏，再次点击恢复显示

### Requirement: 目录操作菜单高亮

目录操作菜单打开时，对应目录项 SHALL 显示选中背景，且菜单定位不得遮挡触发菜单的更多按钮。

#### Scenario: 打开目录操作菜单

- **WHEN** 用户点击目录项右侧更多按钮
- **THEN** 当前目录显示高亮背景，菜单打开后更多按钮仍可见并可再次点击关闭

## ADDED Requirements

### Requirement: 收藏列表紧凑布局

收藏主页 SHALL 使用紧凑但可读的搜索栏、列表卡片、图片、标题、描述和操作区间距；标题不得异常放大或加粗，操作按钮不得被大块空白推离内容。

#### Scenario: 浏览收藏卡片

- **WHEN** 用户在 Pad 或手机上浏览收藏列表
- **THEN** 图片、文字和操作按钮在同一紧凑卡片内对齐，并保留足够的标题与描述可读空间
