# Spec Delta

## Purpose

为已登录用户提供一个简单的跨设备内容中转空间，使同一账号可以在不同设备之间保存和取用一条文字或文件内容。该能力强调单条内容、直接覆盖和账号隔离，避免引入传输任务列表与传输码管理。

## ADDED Requirements

### Requirement: 用户可保存单条文字内容

系统 MUST 允许已登录用户保存文字内容，并将其作为该用户当前唯一内容；保存成功后，用户此前保存的文件或文字 MUST 被覆盖。

#### Scenario: 保存文字并覆盖已有文件

- **WHEN** 已登录用户提交一段文字，且该用户已有一个文件内容
- **THEN** 系统保存文字并返回成功，后续当前内容类型为文字，旧文件不可再通过内容接口读取

#### Scenario: 保存空文字被拒绝

- **WHEN** 用户提交空字符串或仅包含空白字符的文字
- **THEN** 系统拒绝保存并返回可识别的客户端错误，已有内容保持不变

### Requirement: 用户可保存单个文件

系统 MUST 允许已登录用户上传一个文件，并将其作为该用户当前唯一内容；单个文件大小 MUST 不超过 100 MB，保存成功后已有文件或文字 MUST 被覆盖。

#### Scenario: 上传文件并覆盖已有文字

- **WHEN** 已登录用户上传一个不超过 100 MB 的文件，且该用户已有文字内容
- **THEN** 系统保存文件的内容和必要元数据并返回成功，后续当前内容类型为文件，旧文字不可再通过内容接口读取

#### Scenario: 超过 100 MB 的文件被拒绝

- **WHEN** 用户上传大小超过 100 MB 的文件
- **THEN** 系统拒绝此次上传并返回 413 或等价的大小超限错误，已有内容保持不变

#### Scenario: 上传失败不破坏旧内容

- **WHEN** 文件上传在校验或持久化过程中失败
- **THEN** 系统返回错误，且用户此前保存的内容仍然可以读取和下载

### Requirement: 用户只能访问自己的当前内容

系统 MUST 要求内容读取、保存和下载请求经过登录认证，并 MUST 根据当前登录用户身份隔离内容；一个用户不得读取、覆盖或下载另一个用户的内容。

#### Scenario: 同一账号跨设备读取内容

- **WHEN** 用户在设备 A 保存内容后，在设备 B 登录同一账号并请求当前内容
- **THEN** 设备 B 可以获取该账号的当前内容信息，并在内容为文字时获取文字内容或在内容为文件时下载文件

#### Scenario: 不同账号无法访问内容

- **WHEN** 用户 B 登录后请求用户 A 的内容
- **THEN** 系统不返回用户 A 的内容，且用户 B 的内容不会被修改

#### Scenario: 未登录请求被拒绝

- **WHEN** 未携带有效登录凭证的客户端请求内容接口
- **THEN** 系统返回未认证错误，不读取、不保存也不下载任何内容

### Requirement: 用户可读取当前内容

系统 MUST 提供当前内容查询能力；查询结果 MUST 区分文字和文件，文字可被客户端显示和复制，文件 MUST 提供原始文件下载所需的文件名、媒体类型和内容。

#### Scenario: 查询文字内容

- **WHEN** 已登录用户查询当前内容，且当前内容为文字
- **THEN** 系统返回内容类型和文字内容，客户端可以显示文字并提供复制操作

#### Scenario: 查询文件元数据

- **WHEN** 已登录用户查询当前内容，且当前内容为文件
- **THEN** 系统返回文件名、媒体类型、文件大小和更新时间，但不要求将完整二进制内容嵌入 JSON

#### Scenario: 当前没有内容

- **WHEN** 已登录用户查询当前内容，且该用户尚未保存内容
- **THEN** 系统返回明确的空状态，客户端显示当前没有内容，而不是报服务器错误

### Requirement: 用户可下载当前文件

系统 MUST 允许已登录用户下载自己当前保存的文件，并 MUST 使用保存的文件名和媒体类型返回文件；当当前内容不是文件时，下载请求 MUST 被拒绝。

#### Scenario: 下载当前文件

- **WHEN** 已登录用户请求下载自己的当前文件
- **THEN** 系统返回原始文件字节，并使用对应文件名和媒体类型

#### Scenario: 当前内容为文字时请求文件下载

- **WHEN** 用户当前内容为文字但请求文件下载
- **THEN** 系统返回明确的内容类型错误，不返回文字的伪文件下载
