# Proposal

## Why

Web 收藏夹目前只能通过搜索、编辑和人工整理来使用目录内容。用户进入一个收藏目录后，缺少一个能够理解当前目录上下文、回答问题并协助讨论的入口；将 Agnes AI Key 保留在服务端并提供目录级 AI Chat，可以让用户在不离开当前工作空间的情况下探索和整理收藏内容。

## What Changes

- 在 Web 收藏夹页面提供全局悬浮 AI Chat 按钮，用户进入收藏空间或目录后均可打开。
- 打开聊天面板时携带当前空间、当前目录、目录路径和目录收藏摘要作为会话上下文。
- 支持用户围绕当前目录发送中文问题，并显示连续的用户消息与 AI 回复。
- 在 Node 服务端增加需要 JWT 认证的 AI 对话接口，由服务端调用 Agnes AI，浏览器不接触 AI API Key。
- 对目录上下文实施数量、字段和文本长度限制；默认发送标题、描述、来源主机、链接和目录位置等收藏元数据，不默认抓取或发送网页全文。
- 增加 AI 服务配置、超时、输入校验、供应商错误映射、日志脱敏和前后端测试文档。

## Capabilities

### New Capabilities

- `ai-directory-chat`: 提供基于当前收藏目录上下文的认证 AI 对话、悬浮聊天入口、会话交互和敏感信息保护。

### Modified Capabilities

- 无。

## Impact

- Web：修改 `BookmarksView.vue` 或抽取的聊天组件、AI API 客户端及相关样式/测试。
- Node：新增 AI 路由、控制器和服务，扩展配置与环境变量，并更新接口文档和依赖。
- 外部系统：服务端调用 Agnes AI 的 OpenAI 兼容或平台指定接口；需要配置 `AI_API_KEY`、Base URL 和模型名称。
- 安全与费用：AI Key 只保存在服务端；目录上下文发送至第三方模型前需要限制数据范围，并为后续限流/费用控制预留边界。
