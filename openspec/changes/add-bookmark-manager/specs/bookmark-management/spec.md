# Spec Delta

## Purpose

为同一账号提供跨 Android 与 Web 的私人链接收藏和嵌套目录管理能力，使用户能从其他 Android 应用快速保存链接，并在 Web 后台集中整理。

## ADDED Requirements

### Requirement: 认证用户私有数据隔离

系统 SHALL 要求收藏夹及收藏条目接口携带有效登录凭证，并且只能返回或修改凭证所属用户的数据，不接受客户端提交的用户编号作为授权依据。

#### Scenario: 用户读取自己的收藏数据

- **WHEN** 已登录用户请求收藏夹或收藏条目
- **THEN** 系统仅返回该用户拥有的数据

#### Scenario: 用户访问其他用户的数据

- **WHEN** 用户请求读取、修改或删除不属于自己的收藏夹或收藏条目
- **THEN** 系统拒绝该操作且不泄露目标数据内容

#### Scenario: 未登录访问收藏接口

- **WHEN** 请求未携带有效登录凭证
- **THEN** 系统返回未授权响应且不执行数据操作

### Requirement: 嵌套收藏夹管理

系统 SHALL 允许用户创建、读取、重命名、移动、排序和删除私人收藏夹；收藏夹可包含子收藏夹，并 SHALL 防止形成循环父子关系。

#### Scenario: 创建顶层收藏夹

- **WHEN** 用户提交有效名称且未指定父收藏夹
- **THEN** 系统在该用户的根目录创建收藏夹并返回其标识和排序位置

#### Scenario: 创建子收藏夹

- **WHEN** 用户在自己拥有的收藏夹下创建子收藏夹
- **THEN** 系统保存父子关系并在目录列表中返回该关系

#### Scenario: 父收藏夹不属于当前用户

- **WHEN** 用户使用其他用户的收藏夹作为父目录
- **THEN** 系统拒绝创建或移动操作

#### Scenario: 移动形成目录循环

- **WHEN** 用户尝试将收藏夹移动到自身或其后代收藏夹下
- **THEN** 系统拒绝移动并保留原目录结构

#### Scenario: 删除非空收藏夹

- **WHEN** 用户尝试删除仍包含子收藏夹或收藏条目的收藏夹
- **THEN** 系统拒绝删除并返回目录非空的明确错误

### Requirement: 目录列表供客户端构建树

系统 SHALL 以包含标识、父标识、名称和排序位置的扁平列表返回当前用户全部收藏夹，使 Android 和 Web 客户端能够构建一致的目录树。

#### Scenario: 获取多层目录

- **WHEN** 用户拥有多层嵌套收藏夹并请求目录列表
- **THEN** 响应包含所有目录及其父标识和同级排序位置

#### Scenario: 用户没有收藏夹

- **WHEN** 用户尚未创建任何收藏夹
- **THEN** 系统返回空列表而不是错误

### Requirement: 链接收藏管理

系统 SHALL 允许用户创建、读取、编辑、移动和删除链接收藏；每条收藏 SHALL 包含原始 HTTP/HTTPS 链接，可包含标题和描述，并在同一时刻最多属于一个收藏夹。

#### Scenario: 保存到指定收藏夹

- **WHEN** 用户提交有效链接并选择自己拥有的收藏夹
- **THEN** 系统保存收藏并将其关联到该收藏夹

#### Scenario: 保存为未分类

- **WHEN** 用户提交有效链接但未选择收藏夹
- **THEN** 系统保存收藏且将其显示在未分类视图中

#### Scenario: 提交非 HTTP 链接

- **WHEN** 用户提交的值不是有效的 HTTP 或 HTTPS URL
- **THEN** 系统拒绝保存并返回链接格式错误

#### Scenario: 移动收藏

- **WHEN** 用户将收藏条目移动到自己拥有的另一收藏夹
- **THEN** 系统更新该条目的唯一收藏夹归属

### Requirement: 打开收藏原链接

Android 和 Web 客户端 SHALL 为每条收藏提供打开原始链接的明确操作；Android SHALL 请求系统使用可处理该 URL 的外部应用或浏览器打开，无法打开时 SHALL 保留当前页面并提示用户。

#### Scenario: Android 打开收藏链接

- **WHEN** 用户点击收藏条目的“打开链接”按钮且系统存在可处理该 URL 的应用
- **THEN** Android 请求系统在对应应用或外部浏览器中打开原始链接

#### Scenario: Android 保存前试开链接

- **WHEN** 用户在收藏表单中输入链接并点击输入框右侧的打开按钮
- **THEN** Android 请求系统打开当前输入链接且保留未保存的表单内容

#### Scenario: Android 无法打开链接

- **WHEN** 用户点击“打开链接”但系统无法处理该 URL
- **THEN** 应用停留在收藏列表并显示打开失败提示

#### Scenario: Web 打开收藏链接

- **WHEN** 用户点击 Web 收藏条目的标题链接
- **THEN** 浏览器在新标签页打开原始链接且原管理页面保持打开

### Requirement: 链接规范化与重复提示

系统 SHALL 为链接保存规范化值和来源主机，并在同一用户已存在相同规范化链接时返回重复信息，同时允许用户明确选择继续保存。

#### Scenario: 首次保存链接

- **WHEN** 用户保存尚不存在的规范化链接
- **THEN** 系统保存原始链接、规范化链接和来源主机

#### Scenario: 检测到重复链接

- **WHEN** 用户保存的规范化链接已存在于自己的收藏中且未确认重复保存
- **THEN** 系统不创建新条目，并返回已有条目的标识、标题和目录信息

#### Scenario: 用户确认重复保存

- **WHEN** 用户在收到重复提示后明确确认继续保存
- **THEN** 系统创建新条目并保留原有条目

### Requirement: 链接封面与公开元数据识别

系统 SHALL 允许每条链接收藏保存可空封面 URL，并 SHALL 提供认证接口从公开 HTTP/HTTPS 页面提取最终链接、标题、描述及 `og:image` 或 `twitter:image`；识别失败不得阻止用户手动编辑或保存收藏。

#### Scenario: 识别公开页面封面

- **WHEN** 已登录用户提交可安全访问且包含 Open Graph 图片的公开网页链接
- **THEN** 系统返回解析后的绝对封面 URL、标题、描述和重定向后的最终链接

#### Scenario: 页面没有封面

- **WHEN** 公开页面不包含可用封面元数据
- **THEN** 系统返回空封面且客户端仍允许保存收藏

#### Scenario: 用户手动设置封面

- **WHEN** 用户填写有效 HTTP/HTTPS 封面 URL 并保存收藏
- **THEN** 系统保存该封面 URL，并在 Android 与 Web 收藏列表中显示缩略图

#### Scenario: 封面加载失败

- **WHEN** 客户端无法加载已保存的封面图片
- **THEN** 客户端显示来源域名占位图且收藏的其他操作保持可用

### Requirement: 元数据抓取安全限制

系统 MUST 拒绝抓取本机、私网、链路本地和其他非公开目标，并 SHALL 限制重定向次数、请求超时、响应大小及 HTML 内容类型；服务端不得执行页面脚本。

#### Scenario: 提交私网目标

- **WHEN** 用户请求识别 localhost、私网 IP、链路本地地址或解析到这些地址的域名
- **THEN** 系统拒绝请求且不连接目标

#### Scenario: 页面响应过大或超时

- **WHEN** 目标页面超过响应大小、重定向次数或请求时间限制
- **THEN** 系统终止抓取并返回可理解的识别失败响应

### Requirement: 收藏查询与搜索

系统 SHALL 支持按收藏夹、未分类状态和关键词查询当前用户的收藏条目，并提供稳定分页，关键词 SHALL 匹配标题、描述或链接。

#### Scenario: 查询指定收藏夹

- **WHEN** 用户指定自己拥有的收藏夹查询条目
- **THEN** 系统仅返回直接归属于该收藏夹的条目

#### Scenario: 查询未分类条目

- **WHEN** 用户选择未分类视图
- **THEN** 系统仅返回未关联收藏夹的条目

#### Scenario: 搜索收藏

- **WHEN** 用户提交非空关键词
- **THEN** 系统返回标题、描述或链接包含该关键词的当前用户条目

### Requirement: Android 系统分享接收

Android 客户端 SHALL 能从其他应用的系统分享菜单接收文本，并从文本中提取第一个有效 HTTP/HTTPS 链接，随后显示可编辑的收藏表单。

#### Scenario: 分享单个链接到应用

- **WHEN** 用户从其他 Android 应用分享包含有效链接的文本到收藏应用
- **THEN** 应用打开收藏表单并预填链接、来源提示和可推导的默认标题

#### Scenario: 分享文本包含多个链接

- **WHEN** 分享文本包含多个有效链接
- **THEN** 应用使用第一个链接并保留原分享文本作为描述草稿

#### Scenario: 分享文本不包含链接

- **WHEN** 分享文本不包含有效 HTTP/HTTPS 链接
- **THEN** 应用提示未识别到链接且不自动创建收藏

### Requirement: Android 剪贴板链接提示

Android 客户端 SHALL 在用户主动打开应用时检查剪贴板文本，并仅在识别到尚未处理的 HTTP/HTTPS 链接时询问用户是否收藏，不得未经确认自动保存。

#### Scenario: 发现新的剪贴板链接

- **WHEN** 用户主动打开应用且剪贴板包含尚未处理的有效链接
- **THEN** 应用显示非阻塞提示，允许用户打开收藏表单或忽略

#### Scenario: 剪贴板没有链接

- **WHEN** 剪贴板不包含有效链接
- **THEN** 应用正常显示当前页面且不显示错误

#### Scenario: 用户忽略剪贴板链接

- **WHEN** 用户选择忽略当前剪贴板链接
- **THEN** 应用在该链接未变化时不重复提示

### Requirement: Android 快速分类保存

Android 客户端 SHALL 在一个表单中提供链接、可选标题、可选描述和收藏夹选择，并允许用户不填写标题或描述直接保存；目录选择 SHALL 支持最近使用目录和完整目录树。

#### Scenario: 最少操作保存

- **WHEN** 收藏表单已有有效链接且用户直接点击保存
- **THEN** 应用使用默认标题或链接作为展示文本，将条目保存到默认或未分类位置

#### Scenario: 选择嵌套目录

- **WHEN** 用户打开目录选择器
- **THEN** 应用显示最近使用目录及可展开的完整目录层级

#### Scenario: 登录已过期

- **WHEN** 应用接收分享链接但服务端判定登录凭证已失效
- **THEN** 应用暂存待收藏内容，引导用户重新登录，并在登录成功后恢复收藏表单

#### Scenario: 分享链接后自动识别封面

- **WHEN** Android 收藏表单由系统分享或剪贴板链接打开
- **THEN** 应用自动请求一次公开元数据，并只用识别结果填充用户尚未填写的标题、描述和封面

### Requirement: Android 自适应目录导航

Android 客户端 SHALL 在手机尺寸使用可展开的侧边抽屉显示目录，在较宽屏幕使用常驻左侧目录栏，并为每个目录提供新增子目录或添加收藏的入口。

#### Scenario: 手机显示目录

- **WHEN** 应用运行在手机宽度布局
- **THEN** 目录树通过侧边抽屉显示且主内容保持可用

#### Scenario: 宽屏显示目录

- **WHEN** 应用运行在宽屏 Android 设备
- **THEN** 目录树常驻左侧并与收藏列表同时显示

### Requirement: Web 收藏夹后台管理

Web 客户端 SHALL 在现有“工具”菜单下提供收藏夹页面，允许用户浏览目录树、管理目录、搜索收藏以及创建、编辑、移动和删除链接收藏。

#### Scenario: 从工具菜单进入收藏夹

- **WHEN** 已登录用户选择“工具”下的“收藏夹”
- **THEN** Web 打开收藏夹管理页并显示与 Android 相同的目录和条目数据

#### Scenario: Web 修改后跨端可见

- **WHEN** 用户在 Web 中移动或编辑收藏条目并保存
- **THEN** Android 客户端下次刷新时显示更新后的数据

### Requirement: 客户端凭证保护

Android 客户端 MUST 将登录令牌保存在操作系统提供的安全存储中，不得将令牌写入普通偏好设置或日志；客户端日志不得记录收藏描述正文或完整认证头。

#### Scenario: Android 保存登录状态

- **WHEN** 用户成功登录 Android 客户端
- **THEN** 应用将令牌写入安全存储并用于后续 API 请求

#### Scenario: 用户退出登录

- **WHEN** 用户在 Android 客户端退出登录
- **THEN** 应用删除本地令牌和待提交的敏感会话状态
