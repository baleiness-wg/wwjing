# data-transfer 模块规格说明

- 版本：202610150009
- 最后更新：2026-10-15
- 模块名称：data-transfer（单条内容跨设备传输）

---

## 业务概述

data-transfer 模块为已登录用户提供单条内容的跨设备中转能力。用户可以保存一段文字或一个文件，并在同一账号的其他设备上读取、复制或下载当前内容。每个账号始终只保留一条当前内容，新内容保存成功后覆盖旧内容，不提供传输任务列表、传输码、分享链接或历史版本管理。

### 核心业务流程

- 用户登录后进入数据传输页面，页面通过核心认证信息识别当前用户，不允许客户端自行提交用户编号作为访问依据。
- 用户可以选择保存文字或文件；文字不能为空或只包含空白字符，文件大小不得超过 100 MB。
- 保存成功后，当前账号原有的文字或文件被覆盖；校验失败、上传失败或持久化失败时，原有内容保持不变。
- 用户在同一账号的其他设备登录后，可以查询当前内容；文字内容支持显示和复制，文件内容支持查看元数据和下载原始文件。
- 当前账号没有内容时，查询接口返回明确的空状态，客户端显示空状态而不是服务器错误。
- 不同账号只能访问自己的当前内容，未登录请求不得读取、保存或下载任何内容。
- 当前内容为文字时，文件下载请求返回明确的内容类型错误，不将文字伪装为文件下载。

### 页面布局约束

- 数据传输页面需要区分文字输入、文件选择、当前内容展示和下载操作。
- 当前内容为文字时，页面显示文字内容并提供复制按钮；当前内容为文件时，页面显示文件名、媒体类型、文件大小和更新时间，并提供下载按钮。
- 文件选择或拖拽后应立即显示大小校验结果；超过 100 MB 时禁止提交并提示用户。
- 保存文字或文件时必须显示上传或保存过程中的等待状态，避免页面长时间无响应。
- 保存失败时必须保留当前内容展示，不得因失败操作清空或覆盖页面中的旧内容。
- 没有当前内容时显示明确的空状态提示。

## 接口说明

所有接口均要求携带有效登录凭证，并依据认证上下文确定当前用户，不接受客户端传入的 `user_id` 作为授权依据。

### 查询当前内容

- **接口路径**：`/api/transfer/content`
- **请求方式**：GET
- **请求参数**：无
- **返回参数**：

```json
{
  "errcode": 0,
  "errmsg": "",
  "data": {
    "type": "text",
    "text": "需要在另一台设备查看的内容",
    "fileName": null,
    "mimeType": null,
    "fileSize": null,
    "updatedAt": "2026-10-15T00:09:00Z"
  }
}
```

无内容时，`data` 返回 `null` 或项目统一定义的空状态对象。

### 保存文字内容

- **接口路径**：`/api/transfer/content/text`
- **请求方式**：POST
- **请求参数**：JSON 请求体中的 `text` 字段，必须为非空白字符串。
- **返回参数**：

```json
{
  "errcode": 0,
  "errmsg": "",
  "data": {
    "type": "text",
    "updatedAt": "2026-10-15T00:09:00Z"
  }
}
```

### 保存文件内容

- **接口路径**：`/api/transfer/content/file`
- **请求方式**：POST
- **请求参数**：`multipart/form-data`，字段 `file` 为待保存文件，文件大小不得超过 100 MB。
- **返回参数**：

```json
{
  "errcode": 0,
  "errmsg": "",
  "data": {
    "type": "file",
    "fileName": "inspection-report.pdf",
    "mimeType": "application/pdf",
    "fileSize": 245760,
    "updatedAt": "2026-10-15T00:09:00Z"
  }
}
```

### 下载当前文件

- **接口路径**：`/api/transfer/content/file`
- **请求方式**：GET
- **请求参数**：无。
- **返回参数**：成功时返回原始文件二进制，并通过 `Content-Disposition` 返回保存时的文件名，通过 `Content-Type` 返回保存时的媒体类型。当前内容不是文件时返回内容类型错误。
