# auth 模块规格说明

- 版本：202611010001
- 最后更新：2026-11-01
- 模块名称：auth（账号认证与密码管理）

## 业务概述

auth 模块为 Flutter 客户端和 Web 客户端提供注册、登录和已登录用户修改密码能力。修改密码必须校验当前密码，服务端仅保存新密码的安全哈希。

## 核心业务流程

- 用户登录后从 Web 用户菜单或 Flutter 账户菜单进入修改密码。
- 用户输入当前密码、新密码和确认新密码；客户端在提交前校验新密码两次一致且不为空。
- 服务端依据 Bearer JWT 确定当前用户，不接受客户端提交用户编号作为授权依据。
- 当前密码错误时拒绝更新并返回 401；新密码无效或确认不一致时返回 400。
- 修改成功后客户端清除当前令牌并返回登录页，用户使用新密码重新登录。

## 页面布局约束

- Web 端在顶部用户菜单中提供“修改密码”，使用对话框完成操作。
- Flutter 端在侧边账户区域提供“修改密码”，使用 Material 对话框完成操作。
- 密码输入框必须为隐藏输入，提交期间禁用重复提交。

## 接口说明

### 修改密码

- **接口路径**：`/api/auth/change-password`
- **请求方式**：POST
- **请求参数**：必须携带 `Authorization: Bearer <token>`；JSON 包含 `currentPassword`、`newPassword`、`confirmPassword`。
- **返回参数**：成功返回消息；失败返回 `message`，当前密码错误为 HTTP 401。

```json
{
  "currentPassword": "old-password",
  "newPassword": "new-password",
  "confirmPassword": "new-password"
}
```

```json
{
  "message": "密码修改成功"
}
```
