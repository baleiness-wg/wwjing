# bookmark-app-modes 模块规格说明

- 版本：202610312335
- 最后更新：2026-10-31
- 模块名称：bookmark-app-modes（统一收藏客户端模式）

---

## 业务概述

bookmark-app-modes 模块将厨房收藏和星标收藏收敛为移动端与 Web 端统一的多空间架构。移动端对应单一 Android Flutter 工程，Web 端在工具导航下提供目录化多入口。系统区分“疯狂的厨房”（`cookie` 空间，聚焦做饭菜谱收藏）和“鲸界”（`star` 空间，通用网页图文收藏），共享登录与底层收藏增删改查逻辑，同时保持数据空间与特色能力隔离。

## 核心业务流程

- kitchen flavor 必须与 `APP_TYPE=kitchen` 配对，显示“疯狂的厨房”并只访问 `cookie` 空间。
- star flavor 必须与 `APP_TYPE=star` 配对，显示“鲸界”并只访问 `star` 空间。
- Web 端在“工具”导航下将“收藏夹”组织为二级目录折叠组，分别提供“疯狂的厨房”（读写 `cookie` 空间）与“鲸界”（读写 `star` 空间）两个入口；既有 `/tools/bookmarks` 路由自动重定向到默认入口。
- Web 工具首页展示数据传输与收藏夹模块，并在收藏夹下提供疯狂的厨房与鲸界双卡片。
- Web 整体页面限制最外层容器高度为 95vh，严格禁止出现整页级外部滚动条，内部工作区与侧边栏自适应滚动。
- kitchen 用户点击“今天吃什么”随机按钮时，向服务端发起随机推荐请求并展示菜谱卡片弹窗，支持点击跳转原链接与“换一个”重抽。
- 缺少 `APP_TYPE`、值不受支持或与 flavor 不匹配时，构建或启动必须明确失败，不得静默切换模式。
- kitchen 用户点击“今天吃什么”随机按钮时，先弹出目录范围选择弹窗（默认全选所有目录，可勾选指定目录）；点击“开始随机”后在所选目录中随机抽取并展示结果卡片。
- 随机结果弹窗支持点击右上角刷新图标直接“换一个”（在已选范围内再次随机），点击卡片触发应用定向跳转。
- Bilibili、小红书和抖音链接优先使用对应 App 的 HTTPS App Link 或 Deep Link，失败后打开 App 首页，目标 App 不可用时才回退系统外部链接。
- 小红书短链保存前必须通过元数据接口解析成完整笔记 URL，并原样保留服务端返回的分享查询参数；解析失败时保留表单并阻止保存短链。
- 合并不迁移 `cookie` 或 `star` 数据，用户安装对应新应用并登录后继续读取原空间数据。

## 页面布局约束

- kitchen 主页在 AppBar 显示“今天吃什么”随机按钮，请求进行中禁止重复点击。
- 随机弹窗内容高度不得扩展为全屏，主体只包含标题和一个收藏卡片。
- 随机卡片显示与主页一致的封面、标题和来源信息，但不显示选择框和操作菜单。
- star 主页不得显示随机按钮，也不得发起随机菜谱请求。
- 两种模式延续既有 Material 3 风格和 Pad 宽屏目录布局。
- 悬浮主操作、卡片、按钮和单选状态优先使用 Flutter 官方 Material 3 组件，不手工重复实现官方组件已有的按压、焦点、选中、禁用和无障碍语义。
- “收藏链接”主操作使用标准扩展悬浮按钮视觉，同时保留页面范围内拖动定位；点击打开新建收藏表单，拖动结束不得误触发新建。
- 收藏表单目录入口使用标准卡片与列表项，目录选择器使用标准单选行为呈现“未分类”和完整目录树，并保留层级缩进及在选中目录下新建目录的能力。
- 收藏表单、单条移动、批量移动和目录移动必须复用同一个标准目录树选择器，仅按业务规则调整根选项文案和不可选目录。
- 登录页提供明确的“注册新账号”入口，支持输入用户名密码完成注册并直接自动登录。
- kitchen 模式品牌更名为“疯狂的厨房”，采用做饭主题的专用 App 图标；star 模式及通用侧栏更名为“鲸界”，采用鲸鱼主题的专用 App 图标。
- 侧栏菜单“收藏夹”右侧使用直接新建根目录图标按钮，各目录项保持图标化更多操作菜单。
- 收藏卡片与目录项右侧操作必须使用一致的更多按钮、图标化菜单项和危险操作颜色；相同行为使用相同图标和文字。
- 新增目录必须从统一操作菜单触发独立名称窗口；在目录树中选择父目录后新增时，新目录创建到该父目录下并成为当前选择。
- 目录树列表使用紧凑的官方列表密度，目录之间保持清晰但不过度留白，且不得影响层级缩进和点击区域。
- 收藏条目、子目录和随机结果使用一致的官方 Material 卡片层级；组件标准化不得移除封面回退、编辑选择、操作菜单、目录拖放和随机结果精简规则。
- 主页收藏 item 使用页面表面色的官方轮廓卡片，不使用灰色 filled container 背景。
- 目录内容区只显示直接归属于当前目录的收藏条目；条目拖入子目录后必须从当前目录消失，进入目标子目录后显示。
- 切换目录时立即清除上一目录卡片并显示加载状态；快速连续切换时只接受最后选择目录的响应，避免旧内容闪烁或覆盖。
- 编辑选择模式使用官方 CheckboxListTile 整行切换选择，并隐藏卡片单项菜单；移动和删除统一从顶部批量操作执行。
- 编辑选择模式左上角显示“取消”、右上角显示“保存”并用于退出；右下角只显示“移动”和“删除”，未选择条目时保持禁用，普通收藏 FAB 在编辑期间隐藏。
- 主页 AppBar 不显示刷新按钮，收藏列表保留下拉刷新能力。
- 目录选择弹窗右上角直接显示创建文件夹图标，不使用更多菜单；创建位置取当前选中的父目录。
- 目录选择器新增目录使用当前选中节点下方的内联名称输入项，不打开第二个弹窗；创建成功后刷新树并自动选中新目录。
- 内联新增目录的取消和确认图标使用紧凑居中按钮；确认图标为无背景绿色对勾。
- 目录树选中状态使用与文字相同主题色的极浅背景，同时高亮文字和文件夹图标，不显示 Radio 单选圆点，并保持单选和无障碍选中语义。

## 接口说明

### 获取随机厨房收藏

- **接口路径**：`/api/bookmarks/random?space=cookie`
- **请求方式**：GET
- **请求参数**：查询参数 `space` 必须为 `cookie`；可选查询参数 `folderIds` 为逗号分隔的目录编号集合（如 `1,2,3`）；请求头携带 `Authorization: Bearer <token>`。
- **返回参数**：`item` 为当前用户随机收藏对象；没有可选收藏时为 `null`。

```json
{
  "item": {
    "id": "7",
    "space": "cookie",
    "folderId": "2",
    "title": "晚餐",
    "description": null,
    "coverUrl": "https://example.com/cover.jpg",
    "sourceUrl": "https://example.com/meal",
    "sourceHost": "example.com"
  }
}
```

```json
{
  "item": null
}
```

### 解析收藏链接元数据

- **接口路径**：`/api/bookmarks/metadata`
- **请求方式**：POST
- **请求参数**：JSON 字段 `sourceUrl` 为待解析的 HTTP/HTTPS 链接；请求头携带 `Authorization: Bearer <token>`。
- **返回参数**：`metadata.finalUrl` 为跟随安全重定向后的完整 URL，并同时返回可空标题、描述和封面 URL。

```json
{
  "sourceUrl": "https://xhslink.cn/o/example"
}
```

```json
{
  "metadata": {
    "finalUrl": "https://www.xiaohongshu.com/discovery/item/example?xsec_token=token&share_id=id",
    "title": "示例笔记",
    "description": null,
    "coverUrl": null
  }
}
```
