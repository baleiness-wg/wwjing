# bookmark-management 模块规格说明

- 版本：202610260209
- 最后更新：2026-10-26
- 模块名称：bookmark-management（跨端私人收藏夹）

---

## 业务概述

bookmark-management 模块为同一账号提供跨 Android 与 Web 的私人链接收藏和嵌套目录管理能力。Android Flutter 客户端负责从其他应用的系统分享或用户剪贴板快速接收链接，Web 客户端作为后台管理入口负责集中搜索和整理；二者复用 Node 登录服务、收藏接口和 PostgreSQL 数据。

### 核心业务流程

- 用户通过现有用户名和密码登录 Android 或 Web 客户端，收藏接口依据 Bearer JWT 中的用户身份隔离数据。
- Android 用户可从其他应用分享文本到收藏应用；应用提取第一个 HTTP/HTTPS 链接，并预填标题、描述和目录选择表单。
- 用户主动打开 Android 应用时，如果剪贴板中存在尚未处理的链接，应用显示非阻塞收藏提示，不自动上传或保存剪贴板内容。
- 用户可不填写标题和描述，直接将链接保存为未分类或保存到一个已有收藏夹；目录选择器优先展示最近使用目录。
- Android 快速收藏表单创建新收藏夹时，必须在可滚动的目录树中选择父目录；文件夹选择器必须显示层级缩进，最大高度为屏幕高度的 60%。
- 当网页元数据无法提供标题时，客户端必须根据分享链接的平台和内容标识生成可读标题，不得只使用裸域名作为标题。
- Android 接收包含标题文案的分享文本时，必须优先提取首个链接前的有效文案作为收藏标题，并清理抖音/小红书的固定分享提示；只有没有有效文案时才使用 URL 标题兜底。
- Android 从剪贴板发现链接并由用户确认打开快速收藏时，必须将完整剪贴板文本传入表单；链接仅用于识别和去重，不能替代标题或描述正文。
- 用户可创建最多 8 层的嵌套收藏夹，并对目录进行重命名、移动和排序；系统禁止循环移动，非空目录不得删除。
- 用户进入某个收藏夹后，同级链接和子目录均可拖动；将项目拖到子目录上并释放后，链接移动到该目录，目录成为该目录的子目录。
- 系统保存原始链接、规范化链接和来源主机；检测到同一用户已有相同规范化链接时提示原收藏位置，用户仍可明确选择重复保存。
- Web 用户从“工具 / 收藏夹”进入管理页面，可按目录或未分类状态浏览，通过标题、描述或链接搜索，并创建、编辑、移动、批量移动或删除收藏。
- Android 与 Web 修改同一服务端数据，任一客户端刷新后均显示最新目录和收藏内容。
- 用户可通过收藏条目的明确按钮打开原始链接；Android 对配置为直达首页的平台域名直接启动对应 App，其他已配置平台尝试用原链接唤起对应 App，未安装或唤起失败时回退到系统可处理该链接的外部应用或浏览器，Web 在新标签页打开。
- 每条收藏可保存封面 URL；Android 在接收分享或剪贴板链接时尝试识别公开页面标题、描述和封面，Web 与 Android 均允许重新识别或手动修改封面。

### 页面布局约束

- Android 手机布局使用侧边抽屉显示全部收藏、未分类和目录树；宽屏 Android 设备使用常驻左侧目录栏。
- Android 快速收藏表单在一个页面显示链接、标题、描述和目录，链接有效时保存按钮立即可用。
- Android 收到分享时若登录已过期，必须保留待收藏草稿，重新登录成功后恢复表单。
- Web 收藏夹页采用左侧目录树、右侧搜索和收藏列表的布局；窄屏时改为纵向排列且不得产生页面级横向滚动。
- 每个目录均提供新增子目录和添加收藏入口；目录移动候选项不得包含自身及其后代。
- 当前目录内容区的拖拽目标必须显示悬停高亮；文件夹不得拖入自身或其后代，移动失败时保留原位置并提示错误。
- 收藏保存或更新失败时，客户端必须保留用户已输入的链接、标题和描述。
- Android 收藏列表中的每条收藏必须显示“打开链接”按钮；标题最多显示 30 个字符并限制为最多 3 行，无法交给系统打开时必须保留当前页面并提示失败。
- Android 收藏表单的链接输入框最右侧必须显示“打开链接”按钮，允许用户在保存前验证当前输入链接。
- Android 已配置平台的识别依据为链接主机名与应用包名映射，仅匹配精确域名或其子域名，不通过网页内容猜测应用。
- 抖音视频域名收藏点击打开时 SHALL 优先使用抖音 Deep Link 启动对应视频，不向抖音传递原始网页 URL；无法提取视频标识或 Deep Link 启动失败时启动抖音 App 首页，抖音未安装时才回退到原始链接。
- Android 和 Web 收藏列表应显示封面缩略图；没有封面或图片加载失败时显示来源域名占位，不得影响打开、编辑或删除操作。
- Android 收藏表单中的封面和元数据识别必须后台异步执行，不得阻塞保存；识别按钮仍可手动触发，识别完成后仅回填当前仍对应同一链接的表单。
- Android 收藏列表滚动到底部时自动加载下一页并追加到当前列表，不显示底部分页控件。
- 收藏条目标题必填，描述和链接可为空；非空链接继续保存并参与规范化和重复判断，空链接不参与重复判断。Android 和 Web 编辑界面显示链接，便于确认粘贴内容。
- 收藏条目支持标题和较大描述文本；创建收藏时不再自动识别网页封面。
- 收藏条目图片使用有序图片 URL 数组保存，初期不实现上传控件，但必须预留按收藏条目上传图片的接口。
- Android 应用从后台恢复、返回首页或恢复后的剪贴板首次读取为空时，客户端应在短时间内重试读取剪贴板；只要检测到尚未处理的链接，就在首页显示非阻塞收藏提示。
- Flutter 收藏主页 SHALL 在用户已登录时显示悬浮 AI Chat 按钮；按钮不得遮挡主要收藏操作，点击后打开可关闭的聊天面板。
- Flutter AI Chat SHALL 使用当前应用空间、当前目录、目录路径和当前已加载的收藏元数据作为上下文，不得将 AI API Key 放入客户端。
- Flutter AI Chat SHALL 支持连续追问、发送中状态、失败提示和重试；切换目录或空间后不得继续使用旧目录上下文。
- AI 推荐、建议、比较或筛选具体收藏时应保持自然对话，并将对应收藏的原始链接紧跟在该收藏名称后面的括号中；不得把链接统一堆到回复末尾，也不得要求整段回复使用固定模板。泛泛讨论时可以不带无关链接。Web 与 Flutter SHALL 将 AI 回复中的 HTTP/HTTPS 链接渲染为可点击跳转入口，也不再显示重复的底部推荐来源列表。
- 用户可在目录操作菜单中置顶或取消置顶目录；置顶目录在目录树中优先显示，Web 与 Flutter 排序一致。
- 目录所有者可通过目录操作菜单输入其他用户的用户名共享目录；被共享用户可在相同收藏空间看到该目录及其子目录，并对其中收藏和子目录执行已有操作。
- 目录共享弹窗 SHALL 显示当前已共享用户列表，并允许目录所有者移除指定共享用户；取消弹窗不得新增或删除共享关系。
- Web 与 Flutter 目录树默认折叠；新增收藏或移动收藏时的目录选择器也默认折叠，用户可逐级展开。
- Web 与 Flutter 收起 AI Chat 面板时 SHALL 保留当前空间和目录的会话记录；切换空间或目录时清理旧上下文，应用退出后不持久化会话记录。
- Web 与 Flutter 目录操作菜单弹层 SHALL 从目录操作按钮下方展开，不得覆盖触发菜单的点点点按钮。
- Flutter 左侧导航底部 SHALL 只显示一个“设置”入口；修改密码和退出登录作为设置菜单项显示，不再分别占用导航底部位置。
- Web 与 Flutter 所有收藏空间均 SHALL 显示随机入口，按钮和结果弹窗统一使用文案 `Today`。
- `kitchen` 模式使用 `kitchen` 收藏空间；`star` 模式使用 `star` 收藏空间；未提供 `APP_TYPE` 时默认使用 `star`。旧 `cookie` 标识不再作为应用业务空间名称使用。

## 接口说明

所有收藏接口以 `/api/bookmarks` 开头，要求携带有效的 `Authorization: Bearer <token>` 请求头，并依据认证上下文确定当前用户。客户端不得提交 `userId` 作为授权依据。

### 获取收藏夹列表

- **接口路径**：`/api/bookmarks/folders`
- **请求方式**：GET
- **请求参数**：无
- **返回参数**：当前用户收藏夹的扁平数组，包含目录标识、父目录标识、名称、排序位置和更新时间。

```json
{
  "folders": [
    {
      "id": "1",
      "parentId": null,
      "name": "稍后观看",
      "position": 0,
      "createdAt": "2026-10-26T01:11:00.000Z",
      "updatedAt": "2026-10-26T01:11:00.000Z"
    }
  ]
}
```

### 创建收藏夹

- **接口路径**：`/api/bookmarks/folders`
- **请求方式**：POST
- **请求参数**：`name` 为 1 至 120 个字符；`parentId` 可为空；`position` 为非负整数。
- **返回参数**：创建后的收藏夹对象。

```json
{
  "name": "技术",
  "parentId": "1",
  "position": 0
}
```

### 更新收藏夹

- **接口路径**：`/api/bookmarks/folders/:id`
- **请求方式**：PATCH
- **请求参数**：可提交 `name`、`parentId` 或 `position`；移动后目录深度不得超过 8 层且不得形成循环。
- **返回参数**：更新后的收藏夹对象。

```json
{
  "name": "开发资料",
  "parentId": null,
  "position": 1
}
```

### 删除收藏夹

- **接口路径**：`/api/bookmarks/folders/:id`
- **请求方式**：DELETE
- **请求参数**：路径参数 `id` 为收藏夹标识。
- **返回参数**：成功时返回 HTTP 204；目录包含子目录或收藏时返回 `FOLDER_NOT_EMPTY`。

### 查询收藏条目

- **接口路径**：`/api/bookmarks/items`
- **请求方式**：GET
- **请求参数**：支持 `folderId`、`uncategorized=true`、`query`、`page` 和 `pageSize`；`folderId` 与 `uncategorized` 不得同时提交。
- **返回参数**：按更新时间和标识稳定排序的分页收藏列表及总数。

```json
{
  "items": [
    {
      "id": "9",
      "folderId": "1",
      "itemType": "link",
      "title": "Flutter 布局说明",
      "description": "稍后整理",
      "sourceUrl": "https://example.com/flutter?utm_source=share",
      "normalizedUrl": "https://example.com/flutter",
      "sourceHost": "example.com",
      "metadata": {},
      "updatedAt": "2026-10-26T01:11:00.000Z"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20
}
```

### 创建收藏条目

- **接口路径**：`/api/bookmarks/items`
- **请求方式**：POST
- **请求参数**：`sourceUrl` 为必填 HTTP/HTTPS 链接；`folderId`、`title`、`description` 和 `coverUrl` 可为空；检测到重复后可提交 `allowDuplicate: true` 明确继续保存。
- **返回参数**：创建后的收藏条目；未确认的重复链接返回 HTTP 409、错误码 `DUPLICATE_BOOKMARK` 及已有条目摘要。

```json
{
  "sourceUrl": "https://example.com/flutter?utm_source=share",
  "title": "Flutter 布局说明",
  "description": "稍后整理",
  "coverUrl": "https://example.com/cover.jpg",
  "folderId": "1",
  "allowDuplicate": false
}
```

### 获取单条收藏

- **接口路径**：`/api/bookmarks/items/:id`
- **请求方式**：GET
- **请求参数**：路径参数 `id` 为收藏条目标识。
- **返回参数**：当前用户拥有的收藏条目对象；不存在或不属于当前用户时返回 404。

### 更新收藏条目

- **接口路径**：`/api/bookmarks/items/:id`
- **请求方式**：PATCH
- **请求参数**：可提交 `sourceUrl`、`folderId`、`title` 或 `description`；`folderId: null` 表示移动到未分类。
- **返回参数**：更新后的收藏条目对象。

```json
{
  "folderId": null,
  "title": "新的标题"
}
```

### 删除收藏条目

- **接口路径**：`/api/bookmarks/items/:id`
- **请求方式**：DELETE
- **请求参数**：路径参数 `id` 为收藏条目标识。
- **返回参数**：成功时返回 HTTP 204。

### 识别链接公开元数据

- **接口路径**：`/api/bookmarks/metadata`
- **请求方式**：POST
- **请求参数**：`sourceUrl` 为待识别的公开 HTTP/HTTPS 页面链接。
- **返回参数**：重定向后的最终链接、页面标题、描述和绝对封面 URL；无对应元数据的字段返回 `null`。接口拒绝私网目标并限制超时、重定向和响应大小。

```json
{
  "sourceUrl": "https://example.com/article"
}
```

```json
{
  "metadata": {
    "finalUrl": "https://example.com/article",
    "title": "示例文章",
    "description": "文章摘要",
    "coverUrl": "https://example.com/cover.jpg"
  }
}
```
